# AI Habit Tracker 🧠✅

A full-stack AI-powered habit tracking application built using the MERN Stack and Google Gemini AI. The platform helps users build consistency, track habits, analyze progress, and receive personalized AI-driven coaching.

## ✨ Features

* 🔐 JWT Authentication & Secure Login/Signup
* 📋 Create, Edit, Archive & Delete Habits
* ✅ Daily Habit Tracking with Progress Indicators
* 🔥 Current & Longest Streak Tracking
* 📊 GitHub-Style 90-Day Habit Heatmap
* 🤖 AI Weekly Performance Reports
* 💡 AI Habit Suggestions Based on Goals
* 🚀 AI Streak Recovery Coach
* 💬 AI Habit Analysis Chat Assistant
* 🌅 Personalized AI Morning Motivation
* 📈 Insights Dashboard & Statistics
* 🎨 Light/Dark Mode with Responsive Design

## 🛠️ Tech Stack

**Frontend:** React, Vite, Tailwind CSS, Axios
**Backend:** Node.js, Express.js, MongoDB, Mongoose
**Authentication:** JWT, bcrypt
**AI:** Google Gemini API

## 🚀 Getting Started

### Backend

```bash
cd backend
npm install
npm run dev
```

### Frontend

```bash
cd frontend
npm install
npm run dev
```

Create a `.env` file in the backend:

```env
MONGO_URI=your_mongodb_uri
JWT_SECRET=your_jwt_secret
GEMINI_API_KEY=your_gemini_api_key
```
